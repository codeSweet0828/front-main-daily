# ✨ Moment

> 오늘의 순간을 가볍게 기록하는 감성 라이프 로그 앱

<br />

## 🌿 About

Moment는 감정 기록보다 더 가볍고,
SNS보다 더 개인적인 일상 기록 앱입니다.

하루의 장면들을 사진과 짧은 메모로 남기고,
AI 인사이트를 통해 나의 일상 흐름을 돌아볼 수 있습니다.
